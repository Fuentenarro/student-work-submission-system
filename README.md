# Система сдачи лабораторных работ

Учебный проект описывает цифровую среду курса: преподаватель публикует лабораторные задания, студент отправляет версии работы, а преподаватель фиксирует результат проверки и оценку.

## Назначение

Проект развивает тему лабораторных работ 1-4 - жизненный цикл студенческой работы от публикации задания до получения обратной связи и оценки. В этой версии представлены исходный код и документы проекта.

## Состав проекта

- `docs/requirements.md` - функциональные требования по ролям.
- `CONFIGURATION_MANAGEMENT.md` - перечень конфигурационных единиц и журнал изменений.
- `student_work.py` - консольная программа для работы с заданиями и отправками.

## Возможности системы

- создание и просмотр заданий и сроков;
- отправка работы с отдельными версиями;
- проверка работы и запрос доработки;
- фиксация оценки и просмотр статуса.

## Запуск

Нужен Python 3.10 или новее. Внешние библиотеки не требуются.

```powershell
python .\student_work.py init
python .\student_work.py assignment-add --title "Лабораторная работа 1" --course "ИС-231" --deadline "2026-12-01"
python .\student_work.py assignments
python .\student_work.py submit --assignment-id 1 --student-id "STUDENT-01" --text "Описание выполненной работы"
python .\student_work.py review --submission-id 1 --decision reviewed --comment "Работа соответствует критериям"
python .\student_work.py grade --submission-id 1 --score 90
python .\student_work.py status --submission-id 1
```

После запроса доработки можно отправить следующую версию той же работы. Локальная база SQLite хранит версии и статусы отдельно.

## Управление версиями

Основная ветка - `main`. Новые функции разрабатываются в отдельных ветках и включаются через pull request. Перечень конфигурационных единиц и история изменений ведутся в `CONFIGURATION_MANAGEMENT.md`.
