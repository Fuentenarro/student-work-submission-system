# Функциональные требования

Объект проекта - информационная система учебного курса для управления лабораторными работами.

| Идентификатор | Роль | Требование |
| --- | --- | --- |
| REQ-01 | Студент | Система должна показывать студенту опубликованные задания его курса. |
| REQ-02 | Студент | Система должна показывать студенту срок выполнения выбранного задания. |
| REQ-03 | Студент | Система должна принимать версию работы, отправленную студентом. |
| REQ-04 | Студент | Система должна разрешать студенту отправить исправленную версию после запроса доработки. |
| REQ-05 | Студент | Система должна показывать студенту текущий статус проверки его работы. |
| REQ-06 | Преподаватель | Система должна публиковать лабораторное задание по команде преподавателя. |
| REQ-07 | Преподаватель | Система должна сохранять решение проверки и комментарий преподавателя. |
| REQ-08 | Преподаватель | Система должна сохранять оценку проверенной работы. |
| REQ-09 | Администратор курса | Система должна связывать учетную запись пользователя с ролью и курсом. |

## Граница прототипа

Консольный прототип покрывает публикацию задания, просмотр заданий, отправку версии, просмотр статуса, запись результата проверки и оценки. Вход в систему, управление учетными записями, прием файлов, уведомления и сетевое взаимодействие остаются за границей учебной версии.
