# Управление конфигурацией

## Идентификация проекта

- Название: Система сдачи лабораторных работ.
- Идентификатор: SWSS.
- Базовая версия: 0.1.0.
- Основная ветка: `main`.
- Назначение файла: учет конфигурационных единиц и согласованных изменений проекта.

## Конфигурационные единицы

| Идентификатор | Единица конфигурации | Назначение | Базовая версия |
| --- | --- | --- | --- |
| CI-01 | `README.md` | Назначение проекта и инструкция по запуску | 0.1.0 |
| CI-02 | `docs/requirements.md` | Функциональные требования проекта | 0.1.0 |
| CI-03 | `student_work.py` | Исходный код консольного прототипа | 0.2.0 |
| CI-04 | `.gitignore` | Перечень локальных данных, не включаемых в репозиторий | 0.1.0 |
| CI-05 | `CONFIGURATION_MANAGEMENT.md` | Учет версий, веток и изменений | 0.1.0 |

## Порядок внесения изменений

1. Изменение оформляется в отдельной ветке с понятным названием.
2. Коммиты содержат короткое описание измененной конфигурации.
3. В pull request указываются цель, состав изменения и способ проверки.
4. Изменение включается в `main` после просмотра diff и проверки результата.
5. После слияния обновляются состав единиц конфигурации и журнал изменений.
